一直想要一个自己的角落。社交平台上的东西发出去就沉了，不是自己的；而一个自己的网站，
地址归你、内容归你、样子也归你。今天它终于立起来了。

## 名字是怎么来的

站名想了三轮。「摘星工坊」太用力，「小星球」有点装可爱，最后定了**星野漫游**——
在星空下到处逛逛的意思，和我的 GitHub 名字 Starry 也能对上。反正只是配置里的一行字，
以后想改随时能改。

## 定下来的方案

- 用 **Astro** 搭：写出来的是纯静态页面，快，也好部署
- 放在 **GitHub Pages** 上：免费，我本来就天天泡在 GitHub
- **废话条**直接用 GitHub Issues 当后台：以后手机上发一条 Issue，这里就会自动出现一条动态
- 评论用 giscus，点赞用一个免费的计数服务，访客统计用不蒜子

## 接下来

先让网站跑起来，再一点一点改样子。改版和新功能都会记在[建站日志](/changelog/)里——
这大概也会是这个网站最诚实的一个页面。
