刚入门的时候，「部署」是最吓人的一步：教程一笔带过，报错全看不懂。
其实这件事完全可以交给 AI 带着做——关键是你得会问。下面这段提示词直接复制就能用。

## 提示词模板

```text
我在做一个小网页（纯 HTML/CSS/JS），现在想把它部署到 GitHub Pages。
请一步一步带我完成，每一步都告诉我：
1. 要在哪个界面或命令行里做什么操作；
2. 预期会看到什么结果；
3. 如果报错，把报错信息发给你，由你判断原因。

补充信息：
- 我的 GitHub 用户名是：<你的用户名>
- 项目文件夹在：<你的路径>
- 我还没有 / 已经创建远程仓库（划掉不适用）
- 我已经配置好了 SSH（如果没有，先让 AI 教你配）
```

## 三个经验

1. **报错直接原样发给 AI**，别自己瞎猜，它比你会读报错。
2. 让 AI「一步一步带」而不是「直接给全部命令」，你才真的学到东西。
3. 部署成功后让 AI 讲一遍刚才每一步都干了什么，这一步最涨功力。
